# Issue-003 暫存檔與快取清理失敗被靜默跳過

## 問題

- `services/bilibili/dashMpd.ts` 刪不掉暫存檔就跳過；列出目錄失敗也直接跳過清理。
- `services/localProxy.ts` 快取移除失敗（`remove` 回 false 或丟錯）一律不處理。

## 影響

暫存檔與記憶體快取會慢慢累積。清理是計數與記憶體上限的前提，失敗卻不記錄，下一個「為什麼記憶體一直漲」的排查會從零開始。

## 驗收

- 清理失敗要回報（見 issue-001）。
- 啟動時檢查一次殘留，超過門檻就重建而不是繼續沿用。
- 有測試覆蓋「目錄不存在」「檔案被鎖」兩種失敗。
