# Issue-006 Keychain 失敗時退回沙盒明文

狀態：不再寫明文本；Keychain 失敗時登入只在記憶體，並提示使用者。舊明文副本會被刪除。

## 問題

`services/auth.ts` 在 Keychain 拒絕寫入（鎖定或容量）時，把登入憑證留在沙盒的檔案副本裡繼續使用。

## 影響

README 對外宣稱「登入憑證與敏感 Cookie 妥善存放於系統 Keychain」。退回沙盒等於憑證以明文落地，與宣稱不符，也沒有任何 UI 提示使用者。

## 驗收

- Keychain 寫入失敗時要讓使用者知道，並提供重試。
- 移除沙盒明文副本，或至少加密且只在使用中短暫存在。
- 遷移既有資料：偵測到舊副本就搬進 Keychain 後刪除檔案。
