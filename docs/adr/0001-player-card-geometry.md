# ADR-0001 播放器卡片：一個 surface，幾何靠 frame 與 offset

## 狀態

已採用。

## 決策

播放器只有一個 `VideoPlaybackController` 綁定點，位在 `components/PlayerHost.tsx`。卡片在 App 生命週期內常駐，展開、迷你、全螢幕、關閉都只改這個卡片的 `frame`／`offset`，影片檢視從不卸載再掛回。

- surface 必須跟著第一支影片一起綁定。在 `open()` 之前綁定的 surface，第一支影片會是黑畫面；之後就一路留著。
- 播放頁永遠照「展開尺寸」排版，收合只靠外層裁切。尺寸一變，內部的 `GeometryReader` 與分頁 `TabView` 會逐幀重排。迷你列同理：內容照收好時的寬度排版，外框從 0 長開時才不會被拉開。
- 手勢掛在會移動的卡片上，但位移一律對「靜止的根層」座標空間量。對卡片自身量，誤差會隨卡片下移累積。
- 卡片上緣 1:1 跟手，所以「拖到迷你播放器位置」剛好等於收完。放開時要超過該比例才收。
- 甩動也計算：預測位移最多多算 1/4 路程，避免小閃一下就收。
- 先換模式再清位移。兩個更新若分成兩次重繪，中途會退回展開的幾何。
- 拖曳途中值不變，幾何直接貼著手指；放開後才交給動畫收尾。進場慢、退場快。
- 屬於單一端的圖層立刻離場、在收尾段才進場，卡片變形時不會有半透明殘影。
- 內層動畫用 `geometryGroup` 解耦：位置交給卡片這一層動畫，內層只剩固定座標，否則內層會吃到自己的延遲淡入、晚一步滑進來。
- 關閉後仍要畫最後一格，否則卡片滑走時會露出空白。隱藏位置分兩種：從迷你列關閉時停在分頁列下方，其他情況停在畫面外。
- 全螢幕時 window inset 會變成橫向值，要記住直向的值再還原。橫向時根層比螢幕矮，固定尺寸的 frame 會被置中而留白。
- 縮小動畫期間，`WatchView` 收到的回呼必須是穩定參考，否則整個播放頁會跟著重繪。
- 迷你列是浮動分頁列的尾端：尺寸與內距對齊系統 bottom accessory，圓角要縮到能避開膠囊曲線。

## 後果

幾何只有一處在算，影片不會重新掛載，代價是版面高度與安全區的換算散在 `PlayerHost` 裡，改動時要一起看 `index.tsx` 的 overlay 掛法。
